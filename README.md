# PaperNest – Buyer Persona

This project presents a detailed buyer persona analysis for PaperNest as part of a Digital Marketing Internship project.

## 📌 Project Overview

The buyer persona represents a college student who is interested in affordable, aesthetic, personalized, and practical stationery products.

## 🎯 Key Areas Covered

- Buyer Persona Profile
- Customer Interests & Lifestyle
- Customer Pain Points
- Customer Goals
- Preferred Marketing Channels
- Buying Behavior
- Customer Needs and PaperNest Solutions
- Marketing Insights

## 🛠️ Project Type

Digital Marketing | Customer Research | Buyer Persona Analysis
